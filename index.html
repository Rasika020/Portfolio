03 / HOW I WORK

Good engineering is what holds it together.

I like working across boundaries: model and application, API and interface, fast prototype and maintainable system.

01

Start with the system.

Choose components from the constraints, not the trend. Make data flow, ownership and failure behavior explicit.

02

Make quality observable.

Evaluation, tracing and useful telemetry belong in the engineering loop. A response that looks right is not enough.

03

Keep the core dependable.

Use deterministic software for the things that must be correct. Apply models where they add capability, not uncertainty.
