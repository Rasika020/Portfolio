# Rasika Devanhalli — Engineering Portfolio

A dark, interactive portfolio for Rasika Devanhalli, Software Engineer focused on production GenAI, backend systems and applied AI.

## Interface

- Animated canvas signal network with pointer interaction and reduced-motion support.
- Live Bengaluru clock and scroll-progress indicator.
- Interactive architecture explorer with selectable nodes and implementation notes.
- Command terminal with project, stack, experience and contact commands.
- Filterable project cards with accessible case-file dialogs.
- Responsive layouts, semantic HTML and vanilla JavaScript.

## Run locally

Open \`index.html\` in a browser, or serve the repository root with any static web server. No build step or frontend framework is required.

## Deployment

GitHub Pages is deployed using \`.github/workflows/pages.yml\`. Pushes to \`main\` trigger the deployment workflow.
